# 13 倾角传感器模块

标准教学入口为 [TiltSensor_standard.py](TiltSensor_standard.py)，原厂示例为 [TiltSensor_Demo1.py](TiltSensor_Demo1.py)。标准版保留启动归零、Y轴相对偏角采集及原厂JSON/UDP协议，增加实验信息、CSV完整记录、源码快照和退出清理。

## 教学任务

启动时保持传感器静止，随后缓慢改变倾角，观察归零、正向倾斜、反向倾斜及回到初始位置。填写入口顶部的 `experiment_info`，将 `SLEEP_TIME` 从初始1秒调整为2秒，将 `ANGLE_Y_TARGET_VALUE` 从初始30度调整为50度，至少采集10次后按 Ctrl+C 结束。

目标值只写入记录与上报，不触发报警或判断合格。偏角带正负号，不取绝对值。第一笔成功读取的Y轴值作为本次基准，后续按 `原始Y - 基准Y` 计算；绝对偏差严格小于0.3度时置零，然后保留一位小数。恰好0.3度不进入死区，实际浮点读数须结合CSV核对。程序不进行多点校准、角度跨界展开或精度补偿。

## 板端运行

在 RK3588 Linux 实训箱进入本模块目录：

```bash
python3 TiltSensor_standard.py --check
python3 TiltSensor_standard.py
python3 TiltSensor_standard.py --module 13 --output-dir ./成果输出
```

`--help`、`--check` 不加载动态库；后者只检查配置、入口语法和库文件是否存在，不验证库架构、符号或硬件。运行需要同目录的 `libSmartSensorDriver.so`，标准入口仅依赖Python标准库，无需导入原厂Python封装。通过脚本绝对路径加载库，允许从其他工作目录启动。

硬件配置沿用原厂代码：模块13、LIS2DH12TR、SCL=23、SDA=22、I2C地址0x19、速率400000 Hz。扫描后等待2秒，再检查在线并连接。启动时应保持需要作为零点的姿态。等待时间从一次采集和记录、上报完成后开始，实际采样周期可能较长。

原厂封装未检查 `lis2dh12Init` 的返回值，标准版按负值失败处理；读取按原Demo的0失败约定，并拒绝负返回值和非有限读数。这些约定及角度方向、有效范围仍须板端核对。未照搬Demo中未使用的90度最大值，程序不据此裁剪相对偏角。

## 成果与验收

- 默认归档到运行用户桌面的 `成果输出/姓名或小组/任务项目/`，`--output-dir` 替换根目录。同次CSV与入口源码快照同名，以微秒时间戳区分运行。
- CSV包含自定义实验字段，以及 `记录时间`、`实验累计毫秒`、`模块编号`、`采样序号`、`记录类型`、`原始X(度)`、`原始Y(度)`、`原始Z(度)`、`Y轴基准(度)`、`相对Y(度)`、`目标Y(度)`、`采集间隔(秒)`、`结果`、`错误信息`。每行表示启动归零、一次有效采样、停止或异常事件。归零序号为0；事件没有读数时留空，读取失败不会伪造有效的0度采样。
- `student_data/student_data.json` 保存最近最多5条上报状态，不是完整实验归档。保留原协议拼写 `Name=TileSensor`、`Answer.angleY`、`Target_Value.angleYSensor`，发送到 UDP `127.0.0.1:8088`。每包头为四个4字节小端无符号整数：组ID、包数、包序号、数据长度；数据块最多1000字节。
- 有效采样的三个状态均为1；异常或退出时 `angleY=null`，通信和输出状态为0，释放后连接状态为0。接收端必须结合状态处理空读数。UDP发送成功不代表接收端已收到。
- Ctrl+C、SIGTERM或运行异常进入清理，依次尝试注销倾角传感器、断开模块、注销驱动库和关闭UDP；清理失败记录在CSV。断电或强制杀进程无法保证清理。

提交同次CSV、源码快照及现场观察记录。核对基准、正负偏角、回零表现与采样节奏；软件读数不能独立证明实测角度精度。源码快照复现仍需配套动态库与实训箱环境。
