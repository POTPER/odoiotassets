# 激光测距标准实训模块

标准入口为 [VL53L0X__standard.py](VL53L0X__standard.py)，原演示入口 `VL53L0X_Demo1.py` 保留。

## 学生操作

1. 在标准入口“01 教学任务与用户设置”填写考试编号、项目名称和项目位置。
2. 按题面将 `SLEEP_TIME` 调为 2 秒、`LASER_TARGET_VALUE` 调为 300 mm。初始值分别为 1 秒和 50 mm，目标值只记录和上报，不触发报警。
3. 在 Linux ARM64 实训箱的本模块目录运行：

```bash
python3 VL53L0X__standard.py --check
python3 VL53L0X__standard.py
```

使用 Python 3.8 及以上版本。`--check` 只检查参数、Python 语法和配套文件是否存在，不加载 `.so`、不连接设备。可在 Windows 上进行静态检查；实际运行需要与实训箱架构匹配的驱动库。

改变被测物距离，至少观察 10 次采样，并测试正常、过近和超范围场景，按 Ctrl+C 停止。程序不会在第 10 次自动停止。采集间隔是一次采集和保存完成后的等待时间，实际相邻采样还包含处理耗时。

## 距离与状态

| 原始读数 | 上报距离 | CSV结果 |
| --- | --- | --- |
| 50 ≤ 距离 < 2000 mm | 原始距离 | 有效 |
| 小于 50 或大于等于 2000 mm（含8190） | 0 | 超出有效范围 |
| 返回 -1、None 或读取异常 | 停止时上报0及离线状态 | 运行失败 |

读取成功但超范围时，保留原流程的三个状态值均为 1；因此上报 0 不能证明目标物距离为零。目标值不参与有效范围判断。

## 成果与通信

默认保存至运行设备当前用户桌面的 `成果输出/考试编号/项目名称/`，也可指定：

```bash
python3 VL53L0X__standard.py --output-root ./results
```

每次运行生成同名 CSV 和 Python 源码快照。CSV保留完整历史，实验信息字典字段自动成为列；系统列为：记录时间、采样序号、模块编号、原始距离(mm)、上报距离(mm)、目标距离(mm)、采集间隔(秒)、记录类型、结果、错误信息。采样行记录一次成功读取；初始化、停止、异常与上报失败另记事件行，事件行无距离时为空。读取失败的序号可能没有对应采样行。源码归档仅包含入口，复现还需要本目录配套驱动。

原 `student_data/student_data.json` 保留最近五条，通过 UDP 发到 `127.0.0.1:8088`，字段及每片1000字节的分包格式沿用演示入口。CSV先写入，JSON/UDP失败会追加事件并继续采集，退出码为1。UDP发送成功不代表接收端已收到。正常停止及运行失败均尝试上报离线并释放I2C、模块连接、驱动库与套接字。

## 硬件核对与验收

沿用模块4、SCL 22、SDA 23、I2C地址0x29、400000 Hz。虽入口命名为VL53L0X，现有 `LaserSensor.py` 使用VL53L1寄存器及型号标识0xEACC，实际型号应以实训箱为准；本版本沿用驱动，不宣称已验证VL53L0X兼容性。

提交同次CSV与源码，现场核对距离变化、采样节奏、超范围记录和停止释放。静态检查与模拟验证不能替代板端读数、实际精度和界面接收验收。
