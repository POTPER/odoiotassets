# 17 MP3播放器模块

标准教学入口为 [Mp3Player_standard.py](Mp3Player_standard.py)，原厂示例为 [Player_Demo1.py](Player_Demo1.py)。标准版增加循环播放、参数检查、CSV记录、源码归档及退出停播。

## 教学任务

填写入口顶部的 `experiment_info`，将 `PLAY_DURATION` 和 `LOOP_DELAY` 调整为播放等待10秒、停止5秒。初始值分别为2秒、3秒，均须为有限正数。连续观察至少3轮，核对曲目、音量及停止效果，按 Ctrl+C 结束。

`PLAY_DURATION` 从播放指令返回开始计时；曲目可能提前结束，并不保证等待期间一直发声。`LOOP_DELAY` 从停止指令返回开始计时。音量 `VOLUME` 初始为100，允许0～100整数；实际音量范围和效果须板端确认。默认曲目 `00001.mp3` 必须已存在于播放器模块内部。

## 板端运行

在 RK3588 Linux 上进入本目录运行：

```bash
python3 Mp3Player_standard.py
python3 Mp3Player_standard.py --module 15 --output-dir ./成果输出
```

默认地址15沿用原厂 `modIndex=15`，与目录序号17不同，须按实训箱实际地址核对。通过绝对路径加载同目录 `libSmartSensorDriver.so`，只需 Python 标准库；`--help` 不加载驱动。保留原厂文件，标准版不依赖原厂包装中的 Pillow、NumPy 导入。

`PlayLocalFile` 指播放模块内部曲目，名称使用 GBK 编码；同目录 `adf_music.mp3` 是主机素材，本标准版不调用上传及 `PlayOnline`，不会自动传输该文件。

## 成果与验收

- 默认保存到当前用户桌面 `成果输出/姓名或小组/任务项目/`；`--output-dir` 替换根目录。同次CSV和入口源码同名，重名递增编号。
- CSV每行表示一次动作、轮次完成、生命周期或异常事件。含自定义实验信息，以及 `记录时间`、`实验累计毫秒`、`模块编号`、`轮号`、`动作`、`播放等待(秒)`、`停止时间(秒)`、`曲目`、`音量`、`执行结果`、`错误信息`。轮号0用于初始化及退出。
- 原厂包装只声明播放和停止返回整数，未提供成功码含义。标准版将负值判为失败；`驱动指令成功` 表示调用未返回负值，不证明实际发声。初始化连接要求正值，在线查询要求1。至少现场观察3轮并提交观察记录。
- `student_data/student_data.json` 保留最近最多5条状态，沿用 `Name=Mp3Player`、`Answer.Player_Status`、`Display_Content`、`Target_Value` 及状态字段；按原厂四个小端32位整数组成的包头分包，发送到UDP `127.0.0.1:8088`。状态表示软件指令结果，无播放反馈；UDP发送不证明已接收，JSON不替代完整CSV。
- Ctrl+C、SIGTERM及运行异常触发停播、断开、注销；清理各项独立尝试，失败写入记录。强制结束和断电不能保证执行清理。

提交同次CSV、归档源码及现场验收记录。源码快照复现时仍需原厂驱动和模块内部曲目。已完成语法、帮助及模拟驱动验证，尚未板端实测。
