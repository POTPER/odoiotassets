# 超声波测距标准实训

标准入口为 [Ultrasound_standard.py](Ultrasound_standard.py)，原厂 [Ultrasound_Demo1.py](Ultrasound_Demo1.py) 和 [UltrasoundSensor.py](UltrasoundSensor.py) 保留。标准版包含实验信息、配置检查、CSV 完整历史、同次源码归档、JSON/UDP 上报及退出清理。

## 开始实验

在 RK3588 Linux 板端的本模块目录执行，需要 Python 3、`SensorModule.py`、`RS232Module.py`、`UdpPackage.py` 和 `libSmartSensorDriver.so`。标准入口直接调用串口接口，不依赖原厂高层封装导入的 NumPy。

```bash
python3 Ultrasound_standard.py --help
python3 Ultrasound_standard.py --check
python3 Ultrasound_standard.py
python3 Ultrasound_standard.py --output-root ./成果输出
```

填写入口顶部的 `experiment_info`，按任务把 `SLEEP_TIME` 从默认1秒改为2秒，把 `ULTRASOUND_TARGET_VALUE` 从默认50 mm改为300 mm。移动平整挡板，至少记录10次有效采样，观察正常距离、过近及超范围场景，按 Ctrl+C 结束。异常会停止当前运行，可调整挡板后重新运行，分别提交各次记录。采集间隔是一次采集完成后的等待时间，实际周期还包含串口问询、写文件及上报耗时。

目标距离仅记录和上报，不触发报警。配置允许 `(0, 65535]` 内的有限数，这是两字节解析的数值范围，不代表设备实际量程。

## 硬件与距离解析

沿用原厂配置：模块地址15、串口通道2、TX=23、RX=22、9600及8N1。目录编号19不等于模块地址，现场须核对实际地址及接线。扫描后等待2秒，确认在线、连接模块，再初始化串口。

发送单字节 `A0`，接收缓冲区为4字节。标准版暂按原厂实际代码解析：`distance_mm = (frame[1] << 8) | frame[2]`。例如 `00 01 2C 00` 按此规则解析为300 mm；此帧仅用于解释偏移，不是已验证的设备回包。

原厂演示顶部误写为激光测距/VL53L0X，读取注释则描述三字节拼接后除以1000，与实际代码不一致。标准版采用超声波名称，并暂沿用实际代码的两字节毫米解析。尚未验证帧头、校验、设备型号、实际量程、无效距离编码，也未确认驱动返回值是否等于接收字节数；这些内容及超时参数单位均须结合设备协议和板端核对。

读取返回0时最多问询3次；负值立即失败；正值必须等于4，否则记录异常并停止。距离为0时，依据原厂“遮挡或超范围”的提示作为异常停止，不写入成功采样，也不推断具体原因。其他正值仍可能包含设备特殊编码，须现场确认。这样可避免短回包被补零后当作有效距离。

## 成果与上报

CSV 默认输出至当前运行用户桌面的 `成果输出/考试编号/项目名称/`，文件名含微秒时间戳，同名 `.py` 是本次入口源码归档。`--output-root` 替换“桌面/成果输出”根目录。归档源码运行时仍需本模块配套文件。提交同次 CSV、源码及现场观察记录。

CSV 包含实验信息，以及 `记录时间、采样序号、模块编号、距离(mm)、目标距离(mm)、采集间隔(秒)、记录类型、结果、错误信息`。每次成功采样一行；初始化、停止、运行失败、上报失败及清理失败为独立事件行，其距离为空。采样序号为尝试次数，一次尝试最多含3次无响应问询。文本以公式字符开头时会加单引号。

`student_data/student_data.json` 保留最近5条上报，CSV 保留完整历史。沿用原厂字段：`Name=UltrasoundSensor`，距离为 `Answer.distance_mm`，目标为 `Target_Value.distance_mm`，`Output_Frequency` 为配置间隔。成功采样的三个 `Status` 状态均为1；停止或失败时上报距离0及三个状态0。离线0不属于有效测量。

UDP 通过原厂 `UdpPackage` 发送到 `127.0.0.1:8088`，每片数据最多2000字节，另带16字节小端包头。发送成功只表示本机发送调用完成，接收端显示需现场核对。

## 异常与验收

退出时依次尝试释放串口、断开模块、注销驱动库和关闭 UDP；单项清理失败仍继续其余步骤。运行、上报或清理失败返回非零退出码，正常 Ctrl+C 停止返回0。

验收时核对实验信息、2秒间隔和300 mm目标配置、至少10行成功采样、挡板移动与读数变化、过近及超范围观察记录、接收端显示和停止后的离线状态。距离准确度应使用尺具现场比对。

`--check` 只检查配置、配套文件存在和 Python 语法，不加载动态库。离线模拟可核对解析、异常处理、CSV、归档及上报格式；硬件连接、串口协议和测量精度仍需板端验证。
