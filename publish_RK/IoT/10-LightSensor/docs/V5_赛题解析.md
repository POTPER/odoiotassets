# V5 赛题解析（教师参考）

## 样题正文

**任务：施工通道照明监测**

某施工项目拟根据施工通道的光照变化自动开启照明灯。正式接入照明控制前，项目部将本次工作定名为“通道照明监测”，选取“施工通道01”开展光照采集与判别调试。

本次调试约定：每2秒采集一次光照强度；照度低于100 lx时，标记“照度不足”；照度达到或超过100 lx时，正常记录，为后续自动照明提供判断依据。

现由你使用实训箱中的光照传感器完成模拟调试，依据上述安排配置程序，连续采集10次，通过遮挡与补光检查光照数据及照度不足标记。记录应包含采集时间、监测点位、光照强度及判别结果，并提交本次调试的程序源码和CSV数据记录文件。

100 lx仅为本次模拟调试阈值。

## 学生修改范围

与温度传感器任务同一深度，只要求从题面提取信息并调整顶部配置：

```python
experiment_info = {
    "考试编号": "填写本人实际考号",
    "项目名称": "通道照明监测",
    "监测点位": "施工通道01",
}
LIGHT_TARGET_VALUE = 100
SLEEP_TIME = 2
```

固定采集10次由系统提供，照度比较、采集循环、记录和上报也已实现。学生不需要编写判断函数或操作执行器。学生版初始信息、目标值50 lx和间隔1秒应按题面修改；参考答案入口展示上述配置。

## 判别与验收

| 有效输入 | 数据状态 | 照度不足标记 |
|---|---|---|
| 低于100 lx | 照度不足 | 是 |
| 等于100 lx | 正常 | 否 |
| 高于100 lx | 正常 | 否 |
| 读取失败 | 离线或读取失败 | 留空，实测值也留空 |

比较使用原始有效读数，显示和CSV保留两位小数。有效0 lx属于照度不足，不能与失败混淆。光照数值接近阈值时，应结合原始比较逻辑理解舍入后的显示；相等边界可通过隔离测试核对。

验收时检查个人信息、项目及点位、目标值、监测间隔，以及同次运行的10条有效采集记录。通过遮挡和补光，让记录中出现照度不足与正常两种情况，并核对标记。若仅记录到一种条件，可调整操作后重新运行。

CSV使用学生实际配置进行判别，不自动替换成正确参数。CSV存在或程序正常结束不能单独证明作答正确；应将题目、实际参数、测量值和判别标记对应核对。自动照明仅作为应用背景，成果记录的是照度及不足标记，不记录灯具动作。

## 成果与现场验证

成果位于运行设备用户桌面的 `成果输出/考试编号/项目名称/`，包含CSV及同次实际入口源码；异常时增加异常CSV。正常采集到10次自动结束，提前停止会保留未完成提示。源码及CSV应同次提交。

教师先用参考答案对照，再核对学生保存的实际入口参数和CSV。模拟测试验证代码，实训箱用于验证原厂驱动、模块连接和真实光照变化。V5沿用原Demo1的实际I2C协议，未仅凭OPT3001文件名修改驱动参数。
