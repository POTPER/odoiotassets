# 05 电机模块

标准教学入口为 [MotorModule_standard.py](MotorModule_standard.py)，原厂示例为 [MotorModule_Demo1.py](MotorModule_Demo1.py)。标准版沿用原厂单方向双通道 PWM 控制，增加参数检查、运行记录、源码归档和异常退出清理。

## 教学任务

模拟施工现场设备间歇运行：电机运行 5 秒，停止 5 秒，再次运行。连续观察至少 3 个完整轮次，确认节奏与停转效果，按 Ctrl+C 结束。

在入口顶部填写 `experiment_info`，按题面修改 `MOTOR_ON_TIME` 与 `LOOP_DELAY`。学生初始值分别为 2 秒、3 秒，需自行调整；两者均须为有限正数。`LOOP_DELAY` 从关闭指令完成开始计时，不是两轮开始之间的周期。文件记录与通信可能增加动作间隔，软件计时不代表精密实时控制。

## 板端运行

在 RK3588 Linux 实训箱上，进入本模块目录运行：

```bash
python3 MotorModule_standard.py
python3 MotorModule_standard.py --module 5 --output-dir ./成果输出
```

需要同目录的 `libSmartSensorDriver.so` 及可连接的电机模块，默认模块地址为 5。程序使用 Python 标准库，通过绝对路径加载驱动，不依赖原厂 Python 包的隐式导入。`--help` 不加载硬件驱动。

保留原厂配置：通道 0 对应引脚 12、定时器 0；通道 1 对应引脚 13、定时器 1；低速模式、10 位分辨率、1000 Hz。开启时两通道占空比分别为 0、1023，关闭时均为 0。不提供方向或转速调节。

## 成果与验收

- 默认归档到当前用户桌面下的 `成果输出/姓名或小组/任务项目/`；`--output-dir` 替换成果根目录。同次 CSV 和入口 Python 源码同名，重名时递增编号。
- CSV 每行表示一次控制、轮次完成、生命周期或异常事件，包含实验信息及 `记录时间`、`实验累计毫秒`、`模块编号`、`轮号`、`动作`、`运行时间(秒)`、`停止时间(秒)`、`执行结果`、`错误信息`。轮号 0 用于初始化和退出事件。
- `驱动指令成功` 只说明相关驱动调用未返回负值；`轮次完成` 表示本轮运行与停止等待已结束。它们均不证明电机实际转动或停转。现场须观察至少 3 轮，并核对 CSV 开关间隔与配置。
- `student_data/student_data.json` 保存最近最多 5 条状态，沿用 `Name=MotorModule`、`Answer.Motor_Status` 等原厂字段，并按原厂分包格式发送到 UDP `127.0.0.1:8088`。UDP 发送不代表接收端已收到，JSON 不是完整实验归档。
- Ctrl+C、SIGTERM 和运行异常进入清理流程；各项清理独立尝试，失败写入记录。断电或强制杀进程无法执行 Python 清理。

提交同次 CSV、自动保存的源码及现场验收记录。归档源码是入口快照，复现时仍需本模块驱动库与实训箱环境。
