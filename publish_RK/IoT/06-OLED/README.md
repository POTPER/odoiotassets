# 06 OLED 显示模块

标准教学入口为 [OLED_standard.py](OLED_standard.py)，原厂示例为 [OLED_Demo1.py](OLED_Demo1.py)。标准版沿用原厂 128×64 OLED 文字、图片交替显示方式，增加实验信息、参数检查、CSV 记录、源码归档和异常退出清理。原厂入口与配套文件保留。

## 教学任务

模拟施工现场信息展示：文字页显示英文 `Site Ready`、中文 `设备就绪`，与图片页交替显示，每页停留 3 秒。任务名称为“现场信息轮播调试”，任务位置为“设备管理区01”。连续观察至少 3 个完整轮次，核对显示内容、方向和切换节奏，按 Ctrl+C 结束。

填写入口顶部的 `experiment_info`，按题面修改 `TEXT_EN`、`TEXT_ZH` 和 `DISPLAY_INTERVAL`。初始文字为 `Happy New Year`、`新年快乐`，初始间隔为 2 秒，需由学生调整。间隔必须为有限正数；文字过长可能被屏幕裁切，需现场检查排版。

## 板端运行

在 RK3588 Linux 实训箱的本模块目录执行：

```bash
python3 OLED_standard.py
python3 OLED_standard.py --module 6 --output-dir ./成果输出
```

需要 Python 3、Pillow、本目录的 `libSmartSensorDriver.so`、`Font.ttf`、`pic.bmp` 和可连接的 OLED 模块。标准版直接调用原厂动态库，不依赖 `OLEDSensor.py`、`SensorModule.py` 或 NumPy；`--help` 不加载硬件驱动。驱动、字体和图片均按入口所在目录定位。

默认模块编号 6，SCL 为 22，SDA 为 23。显示保留原厂白底黑字、边框与 180° 旋转；图片从 `(0, 10)` 粘贴，超出画布部分裁切。位图为 1024 字节、按 8 行一页排列，像素值大于 127 点亮，每字节低位对应页内上方像素。

每轮包含文字页和图片页。每页停留时间从绘制调用成功返回开始计时；文件写入、通信及下一次绘制可能增加实际间隔，软件计时不代表精密实时控制。

## 成果与验收

- 默认保存至当前用户桌面下 `成果输出/姓名或小组/任务项目/`；`--output-dir` 替换成果根目录。同次 CSV 与入口源码同名，重名时递增编号。
- CSV 每行表示一次显示、轮次完成、生命周期或异常事件，包含实验信息及 `记录时间`、`实验累计毫秒`、`模块编号`、`轮号`、`动作`、`显示间隔(秒)`、`执行结果`、`错误信息`。轮号 0 为初始化和退出事件。
- `驱动指令成功` 表示相关驱动调用未返回负值；`轮次完成` 表示两页的显示与等待均已完成。现场须检查至少 3 轮的实际内容、方向、清晰度和节奏，结合 CSV 中显示动作的时间间隔验收。
- `student_data/student_data.json` 保留最近最多 5 条状态，沿用 `Name=OLED`、`Answer.OLED_Status`、`Answer.Display_Content`、`Target_Value`、`Output_Frequency` 和三个状态字段。数据按原厂 16 字节小端分包头及每包最多 1000 字节载荷发送至 UDP `127.0.0.1:8088`；发送成功不代表接收端已收到。此文件为状态窗口，不是完整实验归档。
- 状态字段中的连接状态表示程序保存的连接状态，通信和输出状态表示当前事件是否为驱动指令成功；轮次完成、用户停止等事件不属于驱动调用，其通信和输出状态为 0。这些字段不能证明屏幕效果或实时在线状态。
- Ctrl+C、SIGTERM 和运行异常进入清理流程，依次尝试清屏、注销 OLED、断开模块、注销驱动及关闭 UDP。单项失败仍继续清理并记录；断电和强制杀进程无法执行 Python 清理。

提交同次 CSV、自动归档源码与现场观察记录。源码归档仅为入口快照，复现仍需要模块驱动、字体、图片和板端环境。
