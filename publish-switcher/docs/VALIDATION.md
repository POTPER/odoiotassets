2026-11-20：2026.11.20.7，修复 Python 3.8 的 Gitee 403 / file 错误

- 用户设备日志确认：Gitee 仓库 API 先返回 403，随后 AccessDenied.__str__ 访问未初始化的 url，经 tempfile 包装层触发 KeyError: 'file'；仓库顺序查询与逐项检测因此中断。
- 核对 CPython v3.8.10 的 urllib/error.py：HTTPError 在 fp=None 时不初始化响应父类。新增回归测试按该构造行为复现原故障；修复前打印、关闭、资源后备与程序更新后备均能触发相同 KeyError。
- AccessDenied 现在为无正文异常显式提供空响应流，错误提示使用 HTTPError 自身的 filename；fetch/head 包装原生错误时同样不依赖 url，且不关闭没有响应流的旧式原生异常。保留 HTTPError 类型、403 状态、脱敏接口提示、错误链与正常关闭语义。
- 修复后覆盖普通顺序查询中 Gitee 失败转 GitHub、逐项检测保留失败／可用结果、原生无响应正文错误、HEAD 拒绝访问、程序更新公开地址后备及响应关闭。没有绕过 Gitee 403、没有修改用户真实 publish。
