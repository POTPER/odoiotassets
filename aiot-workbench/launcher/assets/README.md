# 启动器图片资源

## 启动图标

将图标命名为 `icon.png` 放在本目录，建议使用 512×512 或 256×256 的透明背景 PNG。
当前 `icon.png` 为用户提供的“金砖职赛.png”原图，未经重新绘制，用于窗口和桌面快捷方式。
替换后重新打开启动器；已安装过桌面快捷方式时，再运行一次 `install-launcher.sh` 更新快捷方式。
## 左侧栏图标

`sidebar-icon.png` 是基于原图创作的五色旋转图标，透明背景，简化了小字和细节，用于左侧栏顶部标志和应用条目。
该文件可单独替换，建议使用正方形透明 PNG；界面会将其清晰缩放到 32 / 23 像素。
替换后重新打开启动器即可，不影响窗口和桌面启动图标。
侧栏图标缺失或损坏时回退到 `icon.png`；两者均不可用时显示默认 AI 标志。

## 封面图片

将背景图片命名为 `background.png` 放在本目录，再重新打开启动器即可。
已附带根据用户赛事海报制作的 2026 城市更新智能建造技术应用赛项封面，编号 BRICS-FS-48；第一行“技能”已按反馈修正。
窗口固定为 1100×620，不允许拉伸。PNG 图片铺满右侧 908×620 内容区，深色主题使用 48% 不透明度，浅色主题提高图片可见度；侧栏单独使用对应主题颜色，不叠加背景图。
背景已重新排版，以适应更均衡的窗口。图片按比例缩放，比例不符时居中裁切，保持图形不变形。建议图片比例约为 1.46:1，文字和标志留出边缘安全距离，右下角预留按钮叠放空间。
安装脚本会安装并复核 Pillow / ImageTk。运行时直接读取原图进行 LANCZOS 缩放和像素混合，不依赖 Tk 反向转换图片，也不使用点阵遮罩。组件缺失或不可用时显示具体错误，不静默降为马赛克式渲染。
没有图片、图片损坏或无法读取时显示内置深色矢量背景，不影响启动和退出。

“启动／运行中”“停止”“查看成果”按钮叠放在图片右下角，不另留底部空白；侧栏底部为设置入口，可切换深浅主题及修改成果目录。界面不再显示大号版本标题和右上角状态标签。
